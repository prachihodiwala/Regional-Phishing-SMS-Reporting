About This System

Regional-Language Phishing SMS Reporting & Community Protection System

🛡️ What is this system?

The Regional-Language Phishing SMS Reporting System helps users report suspicious SMS messages received in regional languages such as Hindi and Gujarati.

The system analyzes reported messages, extracts important indicators and groups similar messages into phishing campaigns.

✨ Key Features

📩

SMS Reporting

Users can submit suspicious SMS messages for analysis.

🔍

Indicator Extraction

The system identifies URLs, phone numbers and money amounts from messages.

🎯

Campaign Detection

Similar SMS messages are grouped using similarity matching.

⚙️ How It Works

  • User submits a suspicious SMS.
  • SMS text is normalized.
  • URLs, phone numbers and amounts are extracted.
  • Message similarity is calculated.
  • Similar messages are grouped into campaigns.
  • Report information is stored in the database.
  • Dashboard and Reports show the collected information.

💻 Technologies Used

HTML CSS Python Flask MySQL Regex

🔐 Privacy & Safety

This system is designed to allow users to manually submit suspicious SMS messages. It does not automatically access the user's private SMS inbox.
